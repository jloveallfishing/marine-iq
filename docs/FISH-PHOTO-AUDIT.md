# Fish identification photo audit

MarineCast 3.0.4 · November 28, 2026

The Rules snapshot records alt text, photographer credit, the source record and applicable license links. Newly selected images come from agency media records or a Wikimedia file record that identifies the species and documents the rights. The viewer fits the complete source frame and uses a larger image only when the source offers a separate suitable size.

| Species | Photo review and remaining work |
| --- | --- |
| White and green sturgeon | Replaced white sturgeon with Justin Dummit’s public-domain USFWS field photo. Green sturgeon uses Steve Martarano’s separate USFWS photo of a Sacramento River juvenile and now has a larger view. Both show handling during fieldwork. An unobstructed adult side profile is still needed for each species. |
| River Chinook | Added Chris Pasley’s public-domain USFWS photo of a summer Chinook from the Columbia River. The fish is held by an angler. |
| Ocean Chinook | A separate, clean marine-phase profile remains a gap. See the salmon comparison guide for marine-phase traits. |
| Coho | Replaced the underwater image with Jon Rather’s public-domain USFWS photograph of an adult at Eagle Creek National Fish Hatchery. A clean marine-phase side profile remains a gap. |
| Striped bass | Replaced the old photo with public-domain USFWS tagging imagery. A larger view is available. |
| Vermilion and canary rockfish | Replaced underwater images with NOAA field photographs credited to Victor Simon and David Csepp, respectively. Wikimedia records document public-domain status. The photographs retain field backgrounds. |
| Sunset rockfish | No individually verified and commercially reusable photo was found. A PFMC stock assessment shows two fish from the vermilion/sunset complex and explains that their individual identities cannot be established externally. The app marks the photo pending. |
| Copper, black, blue, quillback, cowcod and bronzespotted rockfish | The existing source records identify these fish. The existing photos are underwater field references. Out-of-water replacements meeting the quality and rights criteria are still needed. |
| Bocaccio | The existing CC BY-SA 4.0 aquarium photo contains other fish. An unobstructed out-of-water profile is still needed. |
| Yelloweye rockfish | The existing USFWS photo credited to Katrina Liebich remains available. |
| Cabezon, kelp greenling and rock greenling | Existing Monterey Bay National Marine Sanctuary and NOAA reference photos remain available. A consistent out-of-water comparison set is still needed. |
| California halibut and Pacific halibut | The existing NOAA images show the fish on the seafloor. Out-of-water photos with the full outline and eye side clearly visible are still needed. |
| Lingcod and leopard shark | The existing NOAA lingcod and Henrik Kibak’s CC BY 4.0 leopard shark references remain available. Out-of-water profiles with the full body and fins visible are still needed. |
| Dungeness crab | The existing CC0 photo is a close-up. A complete view of the shell and limbs remains a gap. |
| Black bass, bluegill, black crappie and white crappie | The black bass group shows a USFWS largemouth bass explicitly labeled as an example. The panfish card has individually labeled photographs, with USFWS public-domain records for bluegill and black crappie and a CC BY-SA 4.0 file for white crappie. A consistent set of neutral-background profiles remains a gap. |

Images load from source hosts on demand. The Rules snapshot and text identification tips are available through the existing offline app shell. Photo viewing offline depends on browser caching. The development environment rejected direct downloads from external image hosts, so this release includes no locally bundled photo files. Browser tests use image fixtures to check layout, enlargement, fallback behavior and navigation without depending on external image availability.
