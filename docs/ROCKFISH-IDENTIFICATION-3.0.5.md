# Rockfish identification and photo sourcing

MarineCast 3.0.5 · November 28, 2026

## Guides reviewed

- CDFW’s [Fish Identification index](https://wildlife.ca.gov/Fishing/Ocean/Fish-ID) and [Groundfish project](https://wildlife.ca.gov/Conservation/Marine/Groundfish) list [Nearshore Rockfish of California](https://nrm.dfg.ca.gov/FileHandler.ashx?DocumentID=36305&inline=) and the comparison sheets for [Yelloweye, Vermilion/Sunset and Canary](https://nrm.dfg.ca.gov/FileHandler.ashx?DocumentID=138378&inline=), [Copper, Canary and Gopher](https://nrm.dfg.ca.gov/FileHandler.ashx?DocumentID=197164&inline=), [Quillback, China and Black-and-Yellow](https://nrm.dfg.ca.gov/FileHandler.ashx?DocumentID=197176&inline=), [Black versus Blue](https://nrm.dfg.ca.gov/FileHandler.ashx?DocumentID=95080&inline=), and [Yellowtail, Olive and Widow](https://nrm.dfg.ca.gov/FileHandler.ashx?DocumentID=213022&inline=).
- RecFIN publishes *Identification of Common Groundfish Species* for [Northern California](https://www.recfin.org/wp-content/uploads/2025/04/IDENTIFICATION-OF-COMMON-GROUNDFISH-SPECIES-of-Northern-California.pdf) and [Central and Southern California](https://www.recfin.org/wp-content/uploads/2025/04/IDENTIFICATION-OF-COMMON-GROUNDFISH-SPECIES-of-central-and-Southern-California.pdf). The northern file exceeded the document fetcher’s size limit. CDFW and RecFIN list it independently.
- ODFW’s [Rockfish identification tips](https://myodfw.com/articles/rockfish-identification-tips) covers **Blue versus Deacon**. The [California Marine Species Portal](https://marinespecies.wildlife.ca.gov/) supplies California species context and credits named illustrators. The NOAA [juvenile guide](https://repository.library.noaa.gov/view/noaa/4460) and [yelloweye age-class gallery](https://repository.library.noaa.gov/view/noaa/50443/noaa_50443_DS1.pdf) provide additional life-stage photos.

CDFW’s guides contain individually credited images. RecFIN’s index reserves rights. Commercial extraction rights were not established for the photographs in these guides or the ODFW material, so MarineCast links to the originals. It uses ODFW only for species identification. California fishing rules continue to use the existing CDFW and applicable federal sources.

Photos use the published source frames. Photo credits and license links appear in the enlarged viewer. Each new image has an asset-level source record. Several available records depict fish underwater or in field settings. Commercially cleared, neutral-background profiles are still needed for those comparisons. Widow and sunset remain photo gaps. The NOAA gallery provides juvenile yelloweye images by link. No photographs were extracted from identification PDFs. The development environment denied direct downloads from the NOAA repository, so no NOAA PDF images were bundled.
