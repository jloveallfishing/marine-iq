# MarineCast 3.0 private beta

The app remains available without subscriptions, payments, accounts or telemetry. Before sharing a beta link, decide whether the cohort only needs a limited invitation list or needs access control. A public GitHub Pages URL is publicly reachable.

## Tester checklist

- [ ] On a physical iPhone, save a fishing log, favorite location, custom location and favorite species on 2.9.1. Install or launch from the existing Home Screen icon.
- [ ] After the approved 3.0 deployment, check the published workflow for asset parity. Reopen the installed app and verify the 3.0 Beta label. If it resumes on the earlier page, use More → Settings → Check for Updates, then Reload to update. Verify the same permanent URL and all saved items.
- [ ] Open each of the six tabs in portrait and landscape. Check light and dark modes, enlarged text, bottom controls and forecast chart sliders.
- [ ] With a slow connection, pan and zoom the weather map. Confirm prior coverage persists where available, moving wind particles respect Reduce Motion, and unfilled cells stay unfilled. Confirm disconnected forecasts are labeled unavailable.
- [ ] Open MPAs online once, then reopen in Airplane Mode. Check the CDFW retrieval date and official links. Compare Bay and coastal boundary examples with the CDFW map. Try location with consent, then verify uncertainty, the possible-entry warning, stopping warnings and background behavior. Test from a safe location.
- [ ] In Rules, try a Bay preset, a Delta preset, an ambiguous shoreline location and a mismatched manual region. Check dated current and reference states against official sources, and verify expired orders stay hidden.
- [ ] Reopen Rules, saved locations and logs offline. Check that the app distinguishes offline references from forecasts.
- [ ] Under More → Beta feedback, download a test report. Verify it contains only version, type and entered text. Share it privately through the organizer's agreed channel.

## Privacy and release checks

Logs, custom locations, species favorites and appearance are local to the device. MarineCast has no identity or telemetry endpoint. Home GPS requires an explicit button and browser permission. When the user picks a GPS-based forecast, request coordinates go to NOAA/NWS. Solar calculations stay on device. Third-party map, search and photo hosts receive normal network metadata. MPA fixes and alerts stay on device. Feedback export stays local until the tester shares it. Retain a plain-language policy describing local storage, backup sensitivity, third-party requests and deletion before inviting a larger cohort. Review client-side data handling, dependency updates and access controls before adding accounts or remote storage.

The Official source review workflow compares official publications daily and requests a human review on change or fetch failure. It also compares the bundled MPA record geometry with the CDFW FeatureServer. Review changes against the source and keep the existing baseline until a maintainer explicitly records a replacement using the workflow input. Alerts can lag a source publication. The workflow never rewrites Rules. Follow the review dates and patch process in the README.

GitHub Pages verification checks canonical URLs independently of browser state. The browser step verifies a clean launch, matching active worker and a worker-controlled reload. Tests simulate a stale canonical worker, stale HTML and mixed-version assets. The new fallback is present once the device reaches 3.0. The first upgrade from 2.9.1 still uses the updater installed by 2.9.1. For future rollback, publish the last known good code under a higher patch version with matching assets so release discovery advances rather than relying on cache age. Live 3.0 verification requires an approved deployment.

### External forecast comparison

The Forecast page offers a plain HTTPS link to the root of Windy.com. It opens in a separate tab only when the user activates it and sends neither a referrer nor coordinates, trip selections or query parameters. The card uses MarineCast styling and generic icons. There are no Windy assets, widgets, APIs, embeds or data transfers from Windy into MarineCast. The card discloses that the services are unaffiliated and is available without an account or tier restriction. Keep this link-only design in scope for commercial launch review.
