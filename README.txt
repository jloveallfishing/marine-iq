Unzip and publish the contents of this folder to a static HTTPS host, such as GitHub Pages or Cloudflare Pages. Open the resulting URL in Safari, Share > Add to Home Screen > Open as Web App. No paid API keys. Internet required for fresh marine data and map tiles. Offline shell does not cache forecasts. Live API requests and iPhone installation have not been browser-tested. Do not use for navigation or as a boating safety determination. Public static hosting exposes the source code; favorites stay in local browser storage.
